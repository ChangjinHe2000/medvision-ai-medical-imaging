# 新版患者工作台工程验证摘要

证据截止日期：2026-10-05。本文件汇总本地改进版的交付与验证条件；它不是本次 README 更新重新执行的模型实验，也不表示当前公开源码已包含新版临床工作台。

## 数据覆盖

本地正常授权工作区可见 202 个患者身份，原数据库及旧身份保持。按实际覆盖优先级互斥划分：

| 分组 | 身份数 | 含义 |
| --- | --- | --- |
| 有临床事实 | 100 | 已导入检验、用药等临床记录。 |
| 有影像 | 42 | 包含工程合成病例；真实公开影像为 41 名独立患者。 |
| 仅有就诊 | 52 | 有就诊记录，不代表已导入完整诊断、检验或用药。 |
| 仅有基本信息 | 8 | 不补造临床事件，界面明确提示当前缺失。 |

来源包括 HAPI 中的 MIMIC-IV FHIR Demo、OpenMRS 中的 Synthea 兼容数据、历史格式及独立公开影像。不同来源集合可能重叠，不将各来源计数直接相加。OpenMRS 51 个身份当前没有已导入的临床事实，其中 44 人有就诊。

MIMIC 源日期经过上游去标识化平移；未来年份不能理解为现实出生或就诊日历。界面保留原始源值并说明该语义，没有统一减年或补造真实日期。

## 真实影像与模型任务

| 工作流 | 独立规模 | 实际验证 |
| --- | --- | --- |
| LIDC-IDRI CT | 20 名患者 / 20 Studies / 5,130 张源切片 | 受控 OHIF、切片、窗操作、MPR 与阅片 session 授权。 |
| RICORD 胸片 | 21 名患者 / 21 Studies / 21 图 | 可阅片，其中 20 个独立输入满足模型准入并完成 CUDA 推理、结果保存及 UI 显示。 |
| CT 分割 | 上述 CT 中 5 个独立病例 / 1,330 张源切片 | 5 持久任务、6 attempts、5 成功 CUDA forwards；一次 forward 前失败后原任务重试。 |

胸片使用 NIH DenseNet121，展示 14 个模型分数。保留了 6 个额外重复输入任务，因此 26 份胸片结果不是 26 名独立患者。一个胸片输入因解剖覆盖不足在推理前拒收，按冻结候补补足，原失败记录保留。

CT 使用 TotalSegmentator 2.11.0 的 `total`，固定六个肺叶 / 气管类别，1.5 mm，`fast/fastest=false`。每例保存 `mask.nii.gz`、`seg.dcm`、`geometry.json` 和 `seg-metadata.json`，验证加载 SEG 体素 hash 与保存掩膜一致，支持三向叠加、开关、透明度与三维表面旋转。

这些是模型执行及可视化的工程验证。没有匹配医学真值，不提供 Dice、AUC 或分割质量 / 诊断准确率结论。图像检查使用服务器 headless Chromium / SwiftShader，不等于 Mac 实际体验或医学专家评估。

## 临床查询与权限

100 名患者 × 5 个固定 source-gold 事实查询 / 结构化摘要任务，共 500 个用例通过：20 名开发患者 100 个任务、按患者冻结的 80 名最终验收患者 400 个任务。该历史集合现为固定回归，不作为仍未见过的任务或生成式临床泛化结论。

验收范围包含明确源字段、必需字段、缺失提示和患者隔离。另有独立来源语义抽样：30 名患者 / 298 条事实，以及 Decimal 精度核对。抽样、查询通过和 API / DB 一致不表示已证明全部临床字段的医学语义正确。

默认 Copilot 通过确定性工具读取结构化事实并形成摘要。临床事实、来源报告与模型输出保留各自范围；引用读取检查授权、患者、版本与来源。缺失信息不由模型补造。

## 性能与可靠性

本地后续工程实验中，当前无 SQL profiler 条件下，6 个配置 × 3 批 × 200，共 3,600 次正式 warm 请求；最大患者含 51,053 条事件，`limit=100`、并发 10 的合并 P95 为 631.785 ms。这是指定数据和负载下的测量，不是冷启动、全新安装、容量极限或生产 SLA。重复请求不能计为患者数。

指定 worker / receipt / 结果故障窗口已通过隔离故障测试，覆盖租约、重试与持久结果边界；不宣称宿主断电恢复、多机网络分区或 exactly-once 模型执行。本次文档提交没有重跑这些实验。
